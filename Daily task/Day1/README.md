# Day 1 - Java Platform Basics

## JDK, JRE and JVM

### JDK - Java Development Kit
JDK is used to develop Java applications. It contains development tools such as javac, java and javap.

### JRE - Java Runtime Environment
JRE provides the environment required to run Java applications.

### JVM - Java Virtual Machine
JVM executes Java bytecode generated from Java source code.

## Java Execution Flow

.java source code
        ↓
      javac
        ↓
.class bytecode
        ↓
       JVM
        ↓
   Program execution

## Key Difference

- JDK → Develop Java applications
- JRE → Run Java applications
- JVM → Execute Java bytecode
